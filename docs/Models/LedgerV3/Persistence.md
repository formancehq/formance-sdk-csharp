# Persistence

How account volumes are stored (NORMAL, EPHEMERAL, or TRANSIENT)

## Example Usage

```csharp
using FormanceSDK.Models.LedgerV3;

var value = Persistence.Normal;
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Normal`    | NORMAL      |
| `Ephemeral` | EPHEMERAL   |
| `Transient` | TRANSIENT   |
