# State

Current sync state (SYNCING = catching up, FOLLOWING = up to date)

## Example Usage

```csharp
using FormanceSDK.Models.LedgerV3;

var value = State.Syncing;
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `Syncing`   | SYNCING     |
| `Following` | FOLLOWING   |
