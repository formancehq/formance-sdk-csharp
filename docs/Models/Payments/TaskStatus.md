# TaskStatus

Where a task stands, from pending or active through to stopped, terminated or failed

## Example Usage

```csharp
using FormanceSDK.Models.Payments;

var value = TaskStatus.Pending;
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `Pending`    | PENDING      |
| `Active`     | ACTIVE       |
| `Stopped`    | STOPPED      |
| `Terminated` | TERMINATED   |
| `Failed`     | FAILED       |
