# Severity

How serious an alert is, used to route and prioritise notifications

## Example Usage

```csharp
using FormanceSDK.Models.Reconciliation;

var value = Severity.Info;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `Info`     | info       |
| `Low`      | low        |
| `Medium`   | medium     |
| `High`     | high       |
| `Critical` | critical   |
